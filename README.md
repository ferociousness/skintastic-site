# skintastic.site

Static landing page for **Skintastic**, hosted free on GitHub Pages with a custom IONOS domain.

## Local preview
Open `index.html` in a browser, or run a tiny server:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files
- `index.html` — the page
- `styles.css` — styles
- `CNAME` — custom domain for GitHub Pages (skintastic.site)

## Deploy
Pushed to GitHub; Pages serves from the default branch root. DNS is pointed from IONOS to GitHub Pages.
